# Сайт образовательного центра «Бурый мишка»

## Что в этой папке

- `index.html`: все страницы сайта и данные для программ, калькулятора, коммуникатора.
- `assets/`: стили, скрипт сайта, шрифты, звуки коммуникатора.
- `img/`: картинки.
- `docs/`: документы (PDF с электронной подписью, бланки DOCX).
- `admin/`: админка, через которую меняется всё на сайте.
- `.nojekyll`, `robots.txt`: служебные файлы для GitHub Pages и поисковиков.

## Как выложить на GitHub Pages

1. Откройте репозиторий сайта на github.com.
2. Удалите старые файлы сайта (прежний большой `index.html` и `docs`), если они там есть.
3. Add file → Upload files: перетащите **всё содержимое этой папки** (файлы и папки целиком), нажмите Commit changes.
4. Settings → Pages → Build and deployment: Source **Deploy from a branch**, Branch **main**, папка **/ (root)**, Save.
5. Через 1–2 минуты сайт откроется по адресу `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/`.

## Админка

Адрес: `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/admin/`

Для входа нужен ключ доступа GitHub (один раз на устройство):

1. Войдите на github.com в аккаунт, где лежит сайт.
2. Откройте https://github.com/settings/personal-access-tokens/new
3. Название любое, срок до года.
4. Repository access: **Only select repositories**, выберите репозиторий сайта.
5. Permissions → Repository permissions → **Contents: Read and write**.
6. Generate token, скопируйте ключ и вставьте в админку.

Ключ хранится только в браузере и отправляется только на api.github.com.

Что умеет админка:

- править любой текст на любой странице прямо на странице, выделять слова жирным, курсивом, цветом, маркером;
- добавлять готовые блоки: текст, текст с фото, карточки, фотогалерею, видео (ВКонтакте, Rutube, YouTube или файл), отзыв, призыв позвонить, вопросы, документы, цифры, шаги, ленту новостей, таблицу;
- менять дизайн всего сайта: готовые сочетания цветов, свои цвета, 13 шрифтов, углы, тени, ширину, отступы, свой CSS;
- менять оформление отдельного блока: фон, цвет и размер текста, выравнивание, колонки, порядок колонок, пропорции фото, показ только на телефоне или только на компьютере;
- создавать новые страницы и пункты меню, скрывать и удалять страницы;
- вести новости: дата, обложка, текст с заголовками и картинками, видео, фото, закрепление;
- включать объявление над шапкой сайта;
- менять картинки (фото само сжимается), ссылки, значки;
- копировать, переставлять, скрывать и удалять карточки, пункты, строки таблиц, вопросы, документы, целые секции;
- загружать документы (PDF, DOCX) и прикладывать их к любому тексту;
- вести программы, калькулятор цен, подбор программы, коммуникатор, навигацию и поиск;
- менять телефон и почту сразу по всему сайту, искать и заменять текст, менять логотип, значок вкладки, цвета, заголовки для поисковиков;
- смотреть сайт перед публикацией (компьютер и телефон);
- хранить историю: любую прошлую версию можно посмотреть и вернуть.

## Важно

- Папку `БМ` с исходными документами **не выкладывайте**: там персональные данные.
- Когда центр начнёт править сайт через админку, не перезаливайте эту папку целиком: так затрутся их правки. Новые доработки делайте поверх `index.html` из репозитория.
